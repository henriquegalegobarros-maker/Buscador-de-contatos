📱 Buscador de Contatos

Projeto desenvolvido durante meus estudos de programação, com o objetivo de praticar os fundamentos de HTML, CSS e JavaScript.

O projeto permite pesquisar contatos pelo nome ou número de telefone, além de cadastrar novos contatos diretamente pela interface.

🚀 Funcionalidades

🔎 Buscar contatos pelo nome ou telefone.

➕ Adicionar novos contatos.

📝 Cadastrar nome e número de telefone.

🧹 Limpar o campo de pesquisa e os resultados.

📱 Layout adaptado para dispositivos móveis.

🛠️ Tecnologias utilizadas

HTML5: estruturação da página.

CSS3: estilização dos elementos e responsividade.

JavaScript: funcionalidades de busca, cadastro e manipulação dos contatos.

💻 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

Arrays e objetos.

Métodos find() e push().

Funções e condicionais.

querySelector().

Eventos com addEventListener().

Manipulação do DOM com innerHTML.

Captura de valores dos inputs.

Responsividade com Media Queries.
